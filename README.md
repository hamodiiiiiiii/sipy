# WASL — Private Chat App

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. افتح مجلد المشروع في Terminal.
3. شغّل:
   npm install
   npm start
4. افتح:
   http://localhost:3000

## الموجود في النسخة
- تسجيل حساب بدون بريد إلكتروني.
- username + password + اسم + bio.
- إنشاء غرف عامة وخاصة.
- كود غرفة عشوائي من 7 أرقام.
- كلمة سر للغرف الخاصة.
- دردشة لحظية عبر Socket.IO.
- رسائل نصية.
- صور وفيديو وصوت وملفات عبر الرفع.
- حالة الكتابة.
- قراءة الرسائل.
- الوضع الليلي والنهاري.
- ملف شخصي.
- SQLite محلي.

## ملاحظات الإنتاج
هذه نسخة أساس كاملة للتطوير المحلي. قبل نشرها على الإنترنت:
- غيّر SESSION_SECRET إلى قيمة عشوائية قوية.
- استخدم HTTPS.
- ضع تخزين ملفات دائم مثل S3/R2 بدلاً من مجلد uploads المحلي.
- أضف CSRF/rate limiting وفلترة MIME وحصص رفع.
- أضف صلاحيات إدارة الغرف والإشراف.
- أضف WebRTC للمكالمات إذا أردت مكالمات صوت/فيديو.
